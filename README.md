# LOOPEACE — Curated Craft Store

## English

LOOPEACE is a single-page artisanal e-commerce storefront built as a 
portfolio project. It showcases a curated collection of handcrafted 
objects across four disciplines: Ceramics, Textiles, Woodwork, and 
Apothecary. Visitors can browse and filter products, add pieces to a 
live cart, and complete their order via WhatsApp with a pre-filled 
message detailing their selection.

### Features
- Filterable product grid with live search
- LocalStorage cart with animated bag drawer
- WhatsApp checkout redirect with pre-filled order summary
- Multi-language UI (English, Español, Français)
- GSAP scroll animations and micro-interactions

### Stack
HTML5 · CSS · Vanilla JavaScript · GSAP

### How to use
Open `index.html` in any browser. No build step required.

## Español

LOOPEACE es una tienda artesanal de una sola página desarrollada como 
proyecto de portafolio. Presenta una colección curada de objetos 
hechos a mano en cuatro disciplinas: Cerámica, Textiles, Madera y 
Apothecaria. Los visitantes pueden explorar y filtrar productos, 
agregar piezas a un carrito en vivo y completar su pedido por WhatsApp 
con un mensaje prellenado con el detalle de su selección.

### Características
- Grilla de productos filtrable con búsqueda en vivo
- Carrito con localStorage y cajón animado
- Redirección a WhatsApp con resumen del pedido prellenado
- Interfaz multilingüe (inglés, español, francés)
- Animaciones GSAP y micro-interacciones

### Tecnologías
HTML5 · CSS · JavaScript Vanilla · GSAP

### Cómo usar
Abrí `index.html` en cualquier navegador. No requiere compilación.
